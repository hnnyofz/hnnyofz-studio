# Blender：从原模到可交付发型

## 新建工作副本

原 GLB 保留哈希，永不覆盖。初始化使用本 skill 的已校准中性头／耳／相机：

```sh
python "$SKILL/scripts/init_project.py" --project ./my-hair \
  --id hair_055 --name '墨黑碎齐刘海' --glb generation/raw/model.glb \
  --blender /path/to/blender --hair-palette '#101622' '#243147' '#3d506a' '#6b839c'
```

ID只是示例，接入前检查目标 catalog。`--fit-box W D H --center X Y Z` 可做统一缩放的粗对位，不是自动验收；长马尾、双髻不可套短发尺寸。无GLB时也能新建空头模项目，在 Blender 中手工制作。

输入模型可能带头皮、脸、眼睛、脖子或肩膀。打开 `model/avatar.blend`，在 **HAIR_WORK** 工作副本里移除这些多余实体；原输入留在 source。不使用肤色色块简单全删作为唯一方法，金发／铜红／浅粉也可能接近肤色。

## 先白模，后材质

1. 对照三视图确定模型哪个方向朝前；本项目正面为 **-Y**、Z向上。旋转和整体尺寸在三维中对齐，不改2D小人头来迁就模型。
2. 先用白模／单色检查头顶比例、额头、太阳穴、鬓角、耳朵与后颈。正面好看并不代表抬头转向也贴头。
3. 整副偏高就整副沿Z平移；不要只拉低发际线，也不要用网页CSS偏移代替真源修改。
4. 两侧根部须有连续体积。缺近侧发根就补贴头闭合cap或外推局部外表；不能把 hair-only 的远侧内壁贴上皮肤来补洞。
5. 参考头顶批准比例控制“超级大头”；双马尾／双髻的设计性横向宽度与顶部过高分开判断。

保存一个可审阅候选，再继续分层／涂色。自然刘海覆盖少量眼睛可接受，按用户美术判断；不要为数字零遮眼把整副头发抬高。

## 真实分层，不是PNG剪一半

清理与粗对位完成后：

```sh
python "$SKILL/scripts/split_hair.py" --project ./my-hair --blender /path/to/blender
```

脚本将工作网格按**世界 Y=0**真正切分并封闭切口，输出完整场景与三个可独立打开的 hair 场景。检查 nonManifoldEdges，修复本来就存在的破洞、自交、漂浮碎片与翻法线；脚本不替代几何审阅。

Y=0只是初始分区：刘海、前侧鬓角和近侧贴头表层归 `hair_front`；后侧体积、长马尾通常归 `hair_back`。**已有模型的明确语义不能被机械重切破坏**。新增贴头cap可能在Y+，但它应在实际头图之前，仍归语义2。脚本对已分层／批准项目拒绝盲目重复初始化。

## 配色、UV与光照

- 免费形状生成通常是白模；三视图颜色不等于模型已经有合格UV纹理。
- 用每款自己的亮／中／暗色板。材质为 Emission 常色或 Emission Color直接连Image Texture；程序材质／复杂PBR要先烘焙成颜色贴图。初始化会把可识别base-color纹理转到该结构，没有贴图则用发色中间调，后续仍需美术审阅。
- 新无纹理模型可启用 `hairLighting: "fixed-normal"`，用真实旋转法线和固定世界光产生层次，再量化到palette。头代理和已有贴图分支不因此重打光。
- 已有AI烘焙颜色时保留其UV细节；若背面偏暗，使用各材质色系内的旋转法线补偿，或者重新烘焙合理光照。发饰、发绳、主发色分族，不能混为一条ramp。
- 若背面明暗在正中出现硬分割，检查烘焙方向和分层材质；用偏心宽高光／连续法线重建体积，不把背面整体提亮成平色。
- 修改外部纹理后，应解包旧 packed 图、加载新图并重新pack，核对 packed bytes 与新PNG。只改磁盘PNG但保留旧packed，会继续渲染旧发色。

## 修已有模型时保留批准部分

对原件复制出新候选。只改需要的几何／材质，尽量保留原UV、已批准发束、色系和光照；新增cap记录对象、范围、语义、源模型SHA与脚本。不要把“每次所有顶点字节都不变”当作模型修改必须条件；如果进行重采样／变换烘焙，比较最终世界空间与实际视觉结果。

有两种变换表示，必须选清楚：

- **baked**：Blender已移动且新导出坐标也已包含移动，runtime不再加 `wholeHairDrop`。
- **pending cached**：缓存还是旧坐标，runtime按记录施加一次世界变换。新sourceSHA仍应对应实际编辑模型；记录缓存的baseline与未应用变换。

优先新导出真实几何；缓存表示仅用于明确的兼容路径。切换表示时清除旧pending，防止站立正常、说话或再构建时二次下移。
